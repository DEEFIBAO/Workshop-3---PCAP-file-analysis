# Sample captures

| File | Source | What it is |
|---|---|---|
| `Networkcapture1.pcap` | [samowononi/Network-Traffic-Analysis-and-Attack-Detection](https://github.com/samowononi/Network-Traffic-Analysis-and-Attack-Detection) | Lab FTP traffic: a legitimate user uploading files, then a long password-guessing run from another host, a successful login and a file download. |
| `Networkcapture2.pcap` | same repository | Lab capture: a half-open TCP SYN scan, then thousands of short FTP connections each trying a login. |
| `compsoc-incident.pcap` | [IvzCyberSec/PCAP_Analysis_Workshop2](https://github.com/IvzCyberSec/PCAP_Analysis_Workshop2) | Fictional web incident: path enumeration, slow login brute force, SQL-injection attempts, session reuse. |

They are used as **regression tests** (`tests/test_reference_captures.py`), not as the specification of the detectors.
They are lab captures containing clear-text credentials; PCAP Sentinel never prints those values, but treat any real capture
as sensitive. All other test traffic is generated by `tests/pcap_factory.py` (deterministic, no network needed).
